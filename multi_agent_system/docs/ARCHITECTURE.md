# 多 Agent 协作需求拆解系统

## 系统概述

本系统基于 AutoGen 框架构建，实现了一个四阶段的多 Agent 协作流程，用于将产品经理的一句话需求自动拆解为完整的技术方案。

## 系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        用户输入层                                │
│                    (一句话需求描述)                              │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Agent 1: 规划 Agent                          │
│              (需求 → 功能模块列表)                                 │
│  - 分析需求意图                                                   │
│  - 识别核心功能点                                                  │
│  - 拆解为模块化结构                                               │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Agent 2: 技术 Agent                           │
│            (模块列表 → 接口设计 + 伪代码)                          │
│  - 为每个模块设计 RESTful API                                     │
│  - 生成伪代码实现                                                │
│  - 定义数据模型                                                 │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Agent 3: 测试 Agent                           │
│              (接口设计 → 测试用例)                                │
│  - 单元测试用例                                                  │
│  - 集成测试用例                                                  │
│  - 边界条件测试                                                  │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Agent 4: 输出 Agent                           │
│              (汇总 → JIRA 任务创建)                               │
│  - 汇总所有输出                                                  │
│  - 生成 JSON 格式方案                                            │
│  - 调用 JIRA API 创建任务                                        │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                        JSON 输出层                               │
│                   (完整技术方案)                                  │
└─────────────────────────────────────────────────────────────────┘
```

## Agent 职责定义

### Agent 1: 规划 Agent (PlannerAgent)
- **输入**: 产品经理的一句话需求
- **输出**: 功能模块列表（JSON 格式）
- **prompt 策略**: 结构化思维，模块化拆分

### Agent 2: 技术 Agent (TechAgent)
- **输入**: 功能模块列表
- **输出**: 每个模块的接口设计和伪代码
- **prompt 策略**: API-first 设计，遵循 RESTful 规范

### Agent 3: 测试 Agent (TestAgent)
- **输入**: 接口设计和伪代码
- **输出**: 测试用例列表
- **prompt 策略**: 覆盖率优先，边界条件考虑

### Agent 4: 输出 Agent (OutputAgent)
- **输入**: 所有 Agent 的输出
- **输出**: JSON 格式完整方案 + JIRA 任务
- **prompt 策略**: 结构化汇总，JIRA 格式适配

## 技术选型

- **框架**: AutoGen 0.4+
- **语言模型**: 支持 OpenAI GPT-4 / Claude / 本地模型
- **消息格式**: JSON
- **JIRA 集成**: REST API

## 特性

1. **长链推理**: 支持多轮对话和上下文传递
2. **状态管理**: 每个 Agent 输出作为下一个的输入
3. **错误处理**: 优雅降级，保留中间结果
4. **可扩展性**: 易于添加新 Agent 或修改流程
5. **JIRA 集成**: 自动创建 JIRA 任务
